# 首版验证范围

本页区分整合层的验证和上游工具自身能力。0.1.0 不宣称所有 Linux 发行版、所有网络环境或全部上游菜单项均已实测。

## 本地离线验证

测试用合成下载内容验证：失败下载、空下载、文件篡改、语法错误不执行；参数中空格与 Shell 特殊字符不被重新解释；取消/未确认/权限不足停止；架构选择正确；压缩包仅调用预期入口；上游非零退出码传递；IPQuality 默认隐私参数。

清单检查核对来源固定提交、SHA256、许可文件、捆绑脚本摘要及重复条目。macOS 本机不执行 Linux 系统修改。

## Linux 集成检查

2026-11-02，0.1.0 候选已在临时 GitHub Linux runner 完成以下验证。公开仓保留同一工作流，可从 [Actions](https://github.com/006IDC/linux-toolbox/actions/workflows/ci.yml) 查看运行结果。

| 环境 | 已通过的实际流程 |
| --- | --- |
| Ubuntu 22.04 / 24.04，AMD64 | 系统信息，NextTrace / ECS 二进制启动，acme.sh / YABS / LinuxMirrors 帮助入口，IPQuality / 科技 lion 入口下载校验 |
| Ubuntu 24.04，ARM64 | 同上，使用对应 ARM64 官方发布文件 |
| Debian 12 / Ubuntu 24.04 容器 | 实际切换软件源、刷新包索引、核对备份文件 |
| Ubuntu 24.04 临时 VM，root | 专属 SWAP 创建和删除、拒绝移除未知文件、创建失败清理、删除中 fstab 编辑失败后的重新启用；BBR 启用后恢复原参数 |

入口回归另有 17 项合成反例测试；全部固定下载项（含 AMD64 / ARM64）均完成获取与 SHA256 比对。测试不连接业务主机、不使用业务凭据、不运行真实付费操作。上述结果证明列出的版本和环境，不外推其他内核及全套上游功能。

## 尚未覆盖的上游系统行为

- Docker 的真实宿主安装、已有容器业务恢复和第三方镜像加速服务。
- SWAP / BBR 在各种内核、文件系统、现有 sysctl 配置及云主机限制下的组合效果。
- 完整 CPU/磁盘/网络压力测评、IP 风险评分准确性、所有流媒体地区结果。
- 真实域名证书签发与部署、DNS 提供商凭据接入和长期续期。
- 科技 lion 全部子菜单、自动安装器及其后续下载链。

这些项目保留上游入口，并非本工具箱逐项验证后的能力保证。需要系统写入的操作先展示来源和影响，再由操作者明确运行。入口摘要只能证明下载的字节与锁定版本一致，不能证明上游没有缺陷。
